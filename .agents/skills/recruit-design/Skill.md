# CrewCore Recruit Design Skill

Use this skill when working on CrewCore Recruit.

## Purpose
Design CrewCore Recruit as a chapter-controlled recruiting and onboarding module inside the CrewCore ecosystem.

## Product context
CrewCore Recruit must help chapters:
- recruit new officials
- capture and qualify leads
- route recruits to the right chapter
- nurture recruits through onboarding
- reduce drop-off
- transition recruits into training and assignment readiness

## Design principles
- preserve chapter autonomy
- keep workflows simple
- make AI useful but not intrusive
- optimize for chapter leaders, recruiters, and assigners
- support future multi-chapter coordination
- make outputs implementation-ready

## Required workflow
Work in this order:
1. Product blueprint
2. User flow
3. Data model
4. UI architecture
5. AI feature design
6. Campaign automation
7. PRD
8. Implementation plan

## Expected outputs
Write outputs into:
- /docs/product
- /docs/architecture
- /docs/prompts
- /docs/decisions

## Key features to account for
- lead capture
- lead scoring
- chapter routing
- onboarding checklist
- training enrollment
- readiness review
- assignment eligibility handoff
- retention follow-up
- recruiter dashboard
- shortage-zone insights

## AI areas
- lead scoring
- onboarding completion probability
- drop-off risk
- chapter fit recommendation
- recruiting message drafting
- readiness summaries
- shortage-zone targeting

## Important rule
Do not assume chapters must abandon existing systems. CrewCore should start as an overlay-first ecosystem.
